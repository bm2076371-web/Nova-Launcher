Nova Launcher 🚀

A Minecraft: Java Edition launcher for Android.

Nova Launcher is a project based on Battly Mobile and the PojavLauncher ecosystem, aiming to create an independent launcher experience for playing Minecraft Java Edition on Android devices.

🎯 Goals

- Create a unique visual identity for Nova Launcher.
- Simplify Minecraft Java Edition version configuration.
- Improve mod and modpack management.
- Provide RAM allocation and performance settings.
- Develop Nova Valk Fix, a system designed to diagnose compatibility issues involving Valkyrien Skies and related mods.
- Gradually expand support for different Minecraft versions, mod loaders, and mods.

🛠️ Nova Valk Fix

Nova Valk Fix is planned to analyze Minecraft logs and identify possible causes of crashes and startup failures, including:

- Missing dependencies.
- Incompatible mod versions.
- Mixin conflicts.
- Initialization failures.
- Issues involving Valkyrien Skies, Create, and related addons.

Initial support is planned for Valkyrien Skies versions 2.4.1.1 and 2.4.0, subject to verification of the exact artifacts and compatible configurations.

The goal is to provide accurate diagnostics and safe fixes whenever possible. Not every issue can be fixed automatically, and each fix must be tested before being considered compatible.

📱 Platform

- Android
- Minecraft: Java Edition
- Compatibility varies depending on the game version, mod loader, and installed mods.
